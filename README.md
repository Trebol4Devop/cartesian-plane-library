# cartesian_plane

Un paquete de Flutter altamente personalizable para renderizar un plano cartesiano interactivo. Permite graficar funciones matemáticas, series de datos, formas geométricas y soporta interactividad avanzada como zoom, paneo y dibujo libre.

## Features

* Renderizado de funciones matemáticas a partir de cadenas de texto.
* Soporte para series de puntos, segmentos, polígonos y puntos individuales.
* Interactividad táctil nativa: zoom (pinch), paneo y tooltips al tocar.
* Herramienta de dibujo libre integrada sobre el lienzo.
* Barra de herramientas flotante y leyenda generada automáticamente.
* Arquitectura delegada para un fácil control programático.

## Getting started

Agrega el paquete a tu proyecto en el archivo `pubspec.yaml`:

```yaml
dependencies:
  cartesian_plane: ^0.0.1
```
